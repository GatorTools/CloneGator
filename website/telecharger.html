Deux façons d'avoir CloneGator : démarrer un PC sur la clé live, sans rien installer, ou installer le paquet sur un Ubuntu. Gratuit, pour tout le monde.

Dernière version

CloneGator

Clé live (.iso) Paquet Ubuntu (.deb)

Clé live

Un système complet de 250 Mo, qui démarre sur CloneGator. Il démarre en BIOS comme en UEFI, Secure Boot actif compris. Écrivez l'ISO sur une clé USB avec Rufus ou Balena Etcher, ou sous Linux :

wget github.com/kevin-belanger/CloneGator/releases/latest/download/clonegator-live.iso
sudo dd if=clonegator-live.iso of=/dev/sdX bs=4M conv=fsync status=progress

Au démarrage, un menu propose le clavier : Français (Canada) par défaut, Canadien multilingue ou Anglais (États-Unis). Rien n'est conservé d'un démarrage à l'autre : les sauvegardes vont sur un disque USB ou un partage réseau.

Paquet Ubuntu

Pour une station de clonage, ou un poste qu'on garde. Testé sur Ubuntu 24.04 :

wget github.com/kevin-belanger/CloneGator/releases/latest/download/clonegator.deb
sudo apt install ./clonegator.deb
sudo clonegator

Pour mettre à jour, les mêmes commandes : apt remplace l'ancienne version et garde vos réglages. Pour désinstaller : sudo apt remove clonegator.
